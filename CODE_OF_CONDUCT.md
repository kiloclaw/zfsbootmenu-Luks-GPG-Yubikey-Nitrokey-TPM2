# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, and assume good intentions. Harassment, insults and personal or political
attacks are not accepted in issues, pull requests, discussions or any other project space.

Report unacceptable behaviour privately to the repository owner through GitHub. Reports are kept confidential. The
maintainers decide on the response, from a warning to a permanent ban, following the enforcement guidelines of the
Contributor Covenant.
